# Interactive Video Curation & Ground-Truth Acquisition Dashboard

Internal tool to ingest YouTube news videos, play them in a custom player,
and let a user draw bounding boxes (text blocks / objects / keyframes) on
paused frames. Every annotation is saved immediately to a database so
nothing is lost, and it all survives server restarts.

## Architecture

```
YouTube URL --> yt-dlp downloads video locally --> served via FastAPI static files
                                                          |
                                                          v
                                        React <video> + <canvas> overlay
                                        (user draws boxes on paused frame)
                                                          |
                                                          v
                                        POST /annotations --> SQLite DB
                                        (bbox coords + optional OCR text)
```

- **Backend:** FastAPI + SQLAlchemy + SQLite (`backend/`)
- **Frontend:** React (Vite) + Tailwind (`frontend/`)
- **DB tables:** `videos`, `annotations` (see `backend/app/models.py`)

Videos are downloaded once with `yt-dlp` and served from local disk -
this is required because YouTube's embedded player does not allow
pixel-level canvas access (cross-origin restrictions), which we need
to draw boxes and crop frames for OCR.

## 1. One-time setup

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**For OCR (stretch goal) to work**, Tesseract must be installed on your
machine (this is a separate binary, not a Python package):
- Windows: install from https://github.com/UB-Mannheim/tesseract/wiki
- Mac: `brew install tesseract`
- Linux: `sudo apt install tesseract-ocr`

If you skip this, everything else still works — `extracted_text` just
stays empty until you type it manually.

### Frontend
```bash
cd frontend
npm install
```

## 2. Running the app (every time)

Open **two terminals**:

**Terminal 1 - backend:**
```bash
cd backend
source venv/bin/activate        # Windows: venv\Scripts\activate
uvicorn app.main:app --reload --port 8000
```
API docs available at http://localhost:8000/docs

**Terminal 2 - frontend:**
```bash
cd frontend
npm run dev
```
Dashboard available at http://localhost:5173

## 3. Using the dashboard

1. Paste a YouTube URL in the left sidebar and click **Add** (or use
   **Batch upload** to paste 30+ URLs at once, one per line).
2. Wait for status to flip from `pending` -> `downloading` -> `ready`
   (backend downloads it with yt-dlp in the background — the list
   auto-refreshes every 4s).
3. Click a `ready` video to open it in the player.
4. Pick a label type (text_block / object / keyframe), pause the video
   wherever you want, and **click-drag a box** on the frame.
5. The box is saved to the database immediately. If Tesseract OCR is
   installed, `extracted_text` auto-fills — edit it in the right panel
   any time (blur the textbox to save your edit).
6. Boxes near the current playback time are shown as an overlay on the
   video so you can see what's already been marked.

## 4. Data persistence

- Database file: `backend/data/app.db` (SQLite) — survives restarts.
- Downloaded videos + thumbnails: `backend/downloads/`
- Cropped annotation snapshots: `backend/downloads/crops/`

None of these are committed to git (see `.gitignore`) — they're
regenerated by re-running ingestion, and the DB persists on disk
between server restarts on its own.

To switch to Postgres later (e.g. for a shared/deployed server):
```bash
export DATABASE_URL="postgresql://user:pass@host:5432/dbname"
```
No code changes needed — `backend/app/database.py` reads this env var.

## 6. API reference (also live at /docs)

| Method | Endpoint            | Purpose                              |
|--------|----------------------|---------------------------------------|
| POST   | `/videos`             | Add one YouTube URL                  |
| POST   | `/videos/batch`       | Add many URLs at once                |
| GET    | `/videos`             | List all videos + status             |
| DELETE | `/videos/{id}`        | Remove a video                       |
| POST   | `/annotations`        | Save a bbox annotation (+ OCR)       |
| GET    | `/annotations?video_id=1` | List annotations for a video    |
| PATCH  | `/annotations/{id}`   | Edit extracted_text / label          |
| DELETE | `/annotations/{id}`   | Remove an annotation                 |
